## 💡 Tips for Development

### 1. Adding Real Images
```dart
// Replace placeholder containers with:
Image.network(
  imageUrl,
  fit: BoxFit.cover,
  errorBuilder: (context, error, stackTrace) {
    return Container(color: Colors.grey[300]);
  },
)
```

### 2. Adding State Management
```dart
// Example with Provider:
ChangeNotifierProvider(
  create: (_) => HomeViewModel(),
  child: HomeScreen(),
)
```

### 3. Adding API Integration
```dart
// Example API call:
final response = await dio.get('/studios');
final studios = response.data.map((json) => Studio.fromJson(json)).toList();
```

### 4. Adding Animations
```dart
// Example fade animation:
AnimatedOpacity(
  opacity: _visible ? 1.0 : 0.0,
  duration: Duration(milliseconds: 500),
  child: YourWidget(),
)
```
